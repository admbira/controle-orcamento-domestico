# Controle Orçamento Doméstico

Sistema de gestão financeira pessoal e familiar desenvolvido com a identidade visual Apoia+Empresarial.

## Recursos
- Cadastro de receitas e despesas
- Controle por mês e intervalo de datas
- Gráficos financeiros
- Importação por CSV/TXT
- Exportação CSV
- Impressão ou salvamento em PDF pelo navegador
- Dados salvos no navegador do usuário

## Publicação no GitHub Pages
Settings > Pages > Deploy from a branch > Branch principal ou main > /(root).
