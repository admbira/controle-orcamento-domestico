# Controle Orçamento Doméstico — Versão 3.0 Profissional

Sistema de gestão financeira pessoal e familiar com identidade visual Apoia+Empresarial.

## Recursos
- Dashboard profissional em azul e dourado
- Logomarca Apoia+Empresarial sem nome pessoal
- Cadastro, edição, duplicação e exclusão de lançamentos
- Pesquisa e filtros por categoria, tipo e datas
- Gráficos coloridos
- Paginação de lançamentos
- Importação CSV/TXT
- Exportação CSV
- Backup JSON
- Dados salvos localmente no navegador

## Publicação no GitHub Pages
1. Exclua os arquivos antigos do repositório.
2. Envie todos os arquivos e pastas deste pacote.
3. Vá em Settings > Pages.
4. Selecione Deploy from a branch.
5. Branch: main ou principal.
6. Folder: /(root).
7. Salve e pressione Ctrl + F5 no navegador.
