# Controle Orçamento Doméstico — Versão 2.1 Corrigida

Sistema de gestão financeira pessoal e familiar desenvolvido com a identidade visual Apoia+Empresarial.

## Recursos

- Cadastro de receitas e despesas
- Edição de lançamentos
- Duplicação de lançamentos
- Exclusão de lançamentos
- Pesquisa por descrição, tipo, data ou categoria
- Filtro por categoria
- Controle por mês e intervalo de datas
- Gráficos financeiros com cores corrigidas
- Importação CSV/TXT
- Exportação CSV
- Backup JSON
- Impressão em PDF pelo navegador
- Dados salvos localmente no navegador

## Estrutura


## Publicação no GitHub Pages

1. Envie todos os arquivos e pastas para o repositório.
2. Confirme que existem:
   - index.html
   - css/style.css
   - js/app.js
   - assets/logo.jpeg
   - README.md
   - LICENSE
3. Vá em Settings > Pages.
4. Selecione Deploy from a branch.
5. Branch: principal ou main.
6. Folder: /(root).
7. Salve.
